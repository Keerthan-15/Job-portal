# Open Source Job Portal

This project is a simple Job Portal web application developed using HTML, CSS, and JavaScript.

## Features
- User Registration
- User Login
- Job Posting
- Job Search
- Apply for Jobs
- Job Filtering

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Description
The Open Source Job Portal allows job seekers to find job opportunities and employers to post job listings. Users can register, login, search for jobs, and apply directly through the portal.

This project was developed as part of an internship training program.
